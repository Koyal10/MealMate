# 🍽️ MealMate – Food Ordering Platform

## 📌 Project Description
MealMate is a full-stack food ordering platform that allows customers to browse restaurants, place orders, and track deliveries.

## 👥 User Roles
- Admin
- Customer
- Vendor
- Driver

## 🛠 Tech Stack
- Frontend: HTML, CSS (React – optional)
- Backend: FastAPI
- Database: MySQL

## 📦 Core Modules
- Authentication & Authorization
- User Management
- Order Management
- Vendor Management

## 🚀 Status
Project initiated – Requirement Analysis & System Design completed.
